# Banco-Cajero Automatico (ATM)

La cooperativa "Ahorra Mas" quiere un prototipo sencillo para comprender cómo se comporta el saldo de una cuenta al utilizar diferentes formas de paso de parámetros en C++, El programa permitirá realizar operaciones de depósitos y retiro utilizando *paso por valor, referencia y puntero*, con el objetivo de comparar su comportamiento.

A partir de las funciones proporcionadas, implemente las tres operaciones solicitadas, aplicando correctamente cada mecanismo de paso de parámetros.

# Funciones por implementar:

- *Consultar saldo*, consulta el saldo utilizando paso por valor. Esta funcion debera mostrar el saldo recibido, sin modificar el saldo original.
-*Deposito*, realiza un depósito real, modificando el saldo mediante referencia.
-*Retiro*, realiza un retiro real, modificando el saldo mediante puntero.
